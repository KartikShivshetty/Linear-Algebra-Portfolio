## Suggested evidence format

When adding exported notebooks later, keep each experiment in its own directory with:

```text
experiment-name/
├── README.md
├── notebook.ipynb
└── assets/
```

The supplied portfolio did not include the actual `.ipynb` files, so this repository does not fabricate them.
