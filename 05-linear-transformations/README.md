# Linear Transformations

The supplied portfolio treats transformation ideas through matrix operators, mappings, composition, rotations, shearing, and projections.

## Key connections

- Vectors represent states or coordinates.
- Matrices represent transformations between spaces.
- Composition is represented by matrix multiplication.
- Projections isolate components along selected directions.
- Orthogonal systems provide non-redundant coordinate directions.

## Projection

$$\mathrm{proj}_u(v)=\left(\frac{v\cdot u}{u\cdot u}\right)u$$
