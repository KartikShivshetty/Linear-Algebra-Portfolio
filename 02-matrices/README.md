# Matrices

## Matrices as system operators

The portfolio describes a matrix as an active operator that maps an input vector to an output, represented by:

$$Ax=b$$

### Covered concepts

- Matrix-vector multiplication
- Spatial transformations
- Rotation matrices
- Scaling and mirroring
- Shearing
- Image intensity matrices
- Composition of operators

## Rotation

$$R(\theta)=\begin{bmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{bmatrix}$$

## Horizontal shear

$$S_{horizontal}=\begin{bmatrix}1&k\\0&1\end{bmatrix}$$

The portfolio connects these operations to computer graphics, robotics, navigation, and image processing.
