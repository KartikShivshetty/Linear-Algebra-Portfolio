# Vector Spaces

This module studies the structural degrees of freedom inside vector and matrix systems.

## Core ideas

### Closure under addition

$$u+v\in V$$

### Closure under scalar multiplication

$$c\cdot v\in V$$

### Column space

The column space is the span generated by the columns of a matrix. Its dimension is the rank:

$$\mathrm{dim}(\mathrm{Col}(A))=\mathrm{rank}(A)$$

### Null space

The null space contains vectors mapped to the zero vector:

$$\mathrm{dim}(\mathrm{Null}(A))=n-\mathrm{rank}(A)$$

### Rank–Nullity Theorem

$$\mathrm{rank}(A)+\mathrm{nullity}(A)=n$$

Applications named in the portfolio include circuits, optimization networks, robotics, and machine-learning models.
